# minimal-todo

cli simple hecho en rust para gestionar tareas

## Uso

todo add "desc"     Añadir tarea
todo list           Ver todas
todo list pending   Solo pendientes
todo done <id>      Completar
todo delete <id>    Eliminar
todo edit <id> t    Editar
todo search <texto> Buscar
todo stats          Estadísticas

Atajos: `a`, `l`, `d`, `rm`, `s`, `sts`

## Datos

`~/.local/share/todo-rust/todos.json`
